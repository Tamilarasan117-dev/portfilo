# TAMILARASAN // Cinematic Interactive 3D Developer Portfolio

A next-generation, AAA-gaming inspired interactive 3D developer portfolio website built with **React**, **Three.js**, **React Three Fiber (R3F)**, **Drei**, **GSAP**, and **Tailwind CSS**.

Explore a sprawling cyberpunk metropolis behind the wheel of a high-performance sports coupe, featuring responsive physics, live telemetry HUD, GTA-style walking pedestrians, wet asphalt reflections, and 7 thematic portfolio districts showcasing Tamil Arasan's engineering track record.

---

## 🚀 Key Features

* **🏎️ Playable Vehicle Physics & Telemetry**:
  * Ultra-responsive sports car physics with instant steering authority, smooth acceleration, braking, and drifting.
  * **🔥 Nitro Hyper-Boost**: Surge up to 200 km/h with dual cyan exhaust flames.
  * **🕹️ Flexible Driving Modes**: Full keyboard controls (<kbd>W</kbd>/<kbd>A</kbd>/<kbd>S</kbd>/<kbd>D</kbd>), one-action Mouse Driving (LMB Gas, RMB Brake, Mouse Steer), and on-screen fast-access buttons.
  * **HUD Dashboard**: Real-time digital speedometer, gear selector, 24-step segmented LED tachometer, and live mini-map radar.

* **🌆 Sprawling Cyberpunk Metropolis**:
  * Procedurally generated multi-tier skyscrapers with randomized office night lighting.
  * Overhead highway gantry matrix signs, cyber skybridges, illuminated transit shelters, and roadside infrastructure.
  * Atmospheric night fog, directional moonlight, and volumetric headlight beams cutting through rain and mist.
  * 1,400 animated rain streaks and atmospheric mist particles.

* **🚶‍♂️ GTA-Style Animated Pedestrians**:
  * Dynamic pedestrians walking along sidewalks and crossing at marked crosswalks with synchronized walking cycles and cyber tech apparel.

* **🏛️ 7 Thematic Portfolio Districts**:
  * **District 01 — About Me**: Identity, professional summary, and engineering ethos.
  * **District 02 — Academic Campus**: B.Tech Information Technology (Anna University / Kings Engineering College, 8.5 CGPA).
  * **District 03 — Tech Matrix Tower**: Full-Stack, DSA, Python, Java, TypeScript, AI Agents (Ollama, Cursor, Antigravity).
  * **District 04 — Innovation Labs**: Custom AI Agent System, Project Management System, Engine Dispatch System, CAPEX Tracker.
  * **District 05 — Corporate Plaza**: Industrial experience at Indotech Transformer Limited (Software Developer — Digital Transformation & Networking).
  * **District 06 — Hall of Triumph**: High-impact deployments and academic distinction.
  * **District 07 — Cyber Garage**: Interactive terminal to initiate direct communication and social connections.

## 🎮 Controls

| Action | Keyboard | Mouse / Touch |
| :--- | :--- | :--- |
| **Accelerate (Gas)** | <kbd>W</kbd> or <kbd>▲</kbd> | Hold **Left Mouse Button** or tap **GAS** |
| **Brake / Reverse** | <kbd>S</kbd> or <kbd>▼</kbd> | Hold **Right Mouse Button** or tap **BRAKE** |
| **Steer Left / Right** | <kbd>A</kbd> / <kbd>D</kbd> or <kbd>◄</kbd> / <kbd>►</kbd> | **Move Mouse Left / Right** or tap **◄ A** / **D ►** |
| **Handbrake** | <kbd>Space</kbd> | — |
| **Nitro Boost** | <kbd>Shift</kbd> or <kbd>N</kbd> | Click **NITRO** button |
| **Toggle Camera** | <kbd>C</kbd> | Click **CAM** button (Chase Cam / Orbit Cam) |
| **Enter District** | <kbd>E</kbd> | Click **ENTER DISTRICT** banner |
| **Dismiss Modal** | <kbd>Escape</kbd> | Click **Close Station** |

## 🛠️ Tech Stack

* **Core**: React 18.3, Vite 6
* **3D Graphics**: Three.js, React Three Fiber (R3F), @react-three/drei
* **Post-Processing**: @react-three/postprocessing, postprocessing (Bloom, Vignette, Chromatic Aberration)
* **Animation & UI**: GSAP, Lucide React, Tailwind CSS
* **Deployment**: Vercel

## 📦 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Tamilarasan117-dev/portfilo.git
cd portfilo

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the city!
