## 📽️ Design Philosophy & Overview

This portfolio is an award-winning cinematic experience that channels the raw power, atmospheric depth, and organic resilience of ancient rainforests. Translating industrial software developer **Tamil Arasan's** engineering achievements at **Indotech Transformer Limited** and **Kings Engineering College (8.5 CGPA)** into an immersive, interactive digital ecosystem.

Built with **React**, **Three.js / React Three Fiber**, **GSAP ScrollTrigger**, **Lenis smooth scrolling**, and **Web Audio soundscapes**, every scroll interaction is engineered with physics-driven momentum and 60/120 FPS performance.

## ✨ Key Sections & Interactive Experiences

### 1. 🌲 Hero: "Explore the Unknown"
- **Volumetric God Rays & Depth:** High-resolution rainforest canopy with shifting morning sunbeams.
- **3D Split Typography:** Headlines reveal letter-by-letter with perspective rotations (`rotateX`).
- **Foregound Foliage Scrub:** Jungle leaves part dynamically to the left and right as you initiate scrolling.
- **Bioluminescent Motility:** 85+ floating dust particles drifting with subtle organic sway.
- **Mouse Parallax:** 3D tilt tracking cursor velocity across all axes.

### 2. 🍃 Forest Realm: "Rooted in Resilience"
- **Pinned Scroll Zoom:** The ancient canopy scales smoothly from 1.0x to 1.4x while pinned, drawing the user into the forest floor.
- **Dual Glassmorphism Cards:** Sliding in from opposing 3D angles to showcase software architecture principles, algorithmic roots, and industrial foundations.
- **Storytelling:** Connecting biological network resilience to mission-critical enterprise systems.

### 3. 🌊 Waterfall Realm: "The Living Waterfalls"
- **Realistic Cascades & Flowing Chutes:** 5 continuous cascading water chutes plunging down canyon cliff walls with downward gravity acceleration, light refraction, and white-water foam streaks.
- **3D Drone Camera Plunge:** Scroll-controlled camera dives 2.55x deep into the waterfall chasm.
- **Spray & Mist Simulation:** Over 140 depth-projected mist vapor particles rising and flying toward the screen.
- **Acoustic Waterfall Rumble:** Web Audio API sound generator delivering low-frequency roaring waterfall acoustics.
- **Flow Rate Controls:** Toggle between **Torrential (Heavy Monsoon)** and **Cinematic (Mist)**.
- **Indotech Production Platforms:** Staggered reveal of the 3 flagship enterprise systems deployed by Tamil Arasan.

### 4. ⛰️ Mountain Realm: "Summit of Mastery"
- **Golden Sunrise Peaks:** Mountain landscape with floating horizontal cloud strata.
- **AI Developer Toolchain:** Dedicated matrix spotlighting **Cursor**, **GitHub Copilot**, **Codex**, **Claude**, **Antigravity**, and the **Ollama Framework**.
- **Interactive Competency Meters:** Real-time animated percentage bars for Full-Stack Development (92%), Workflow Automation (94%), and IT Networking (85%).
- **Academic Honors:** Kings Engineering College (Affiliated to Anna University), Chennai — **CGPA: 8.5 / 10.0** (First Class with Distinction).

### 5. 🪐 3D Biosphere: Interactive Three.js Realm
- **Procedural 3D Leaves:** Extruded organic leaf geometries swaying in real-time procedural wind physics.
- **Bioluminescent Firefly Swarm:** 220+ glowing particles that track and swirl around the mouse pointer.
- **Environment Presets:**
  - 🌿 **Lush Canopy:** Emerald ambient forest glow.
  - ☀️ **Golden Dawn:** Warm amber sunrise light rays.
  - 🌙 **Night Fireflies:** Dark starry cosmos with glowing jade motes.

### 6. 🏛️ Systems & Innovations Showcase

- **Autonomous Local AI Agent:** High-performance local inference with Ollama, dynamic tool calling (automated time calculations, cloud integrations, document parsing), and context window memory optimization.
- **Interactive Blueprint Modals:** Deep dive into architecture diagrams, problems, solutions, and enterprise metrics.

### 7. 📡 Transmission to Chennai & Curriculum Vitae

## 🛠️ Tech Stack

- **Core:** [React 18](https://reactjs.org/), [Vite 5](https://vitejs.dev/), [JavaScript (ESNext)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/), Custom Glassmorphism, CSS 3D Transforms

- **Animation:** [GSAP 3](https://greensock.com/gsap/), [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/), [Framer Motion](https://www.framer.com/motion/)

- **Icons & Effects:** [Lucide React](https://lucide.dev/), [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio:** Web Audio API & HTML5 Audio Engine

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Tamilarasan117-dev/portfilo.git
cd portfilo

# 2. Switch to the nature portfolio branch
git checkout nature-protfilo

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Visit **`http://localhost:3000`** in your browser.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
